# "View docs" links for the app

Use these exact addresses when you update the app. Every page here is checked on each build. If one goes missing, the build fails, so these addresses stay stable.

Links should open in a new browser tab (`target="_blank"`). Don't embed the docs inside the app.

|---|---|
| Home page footer, **View docs** | https://docs.seloapps.com/ |
| Upsell offer form, checkout block guide | https://docs.seloapps.com/guides/checkout-thank-you-blocks/ |

## Notes

- The Upsells page in the app has a **View docs** card under **Help & Resources**, described as "Browse guides and tutorials". This list doesn't cover it. Pointing it at https://docs.seloapps.com/ would match the home page footer link.
- All addresses end in `/`. Keep the trailing slash so there's no extra redirect.
- You can link to a section of a page with its heading anchor. For example, https://docs.seloapps.com/troubleshooting/#my-offer-isnt-showing goes straight to that answer.
