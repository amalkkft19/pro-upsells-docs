Show discount code offers in the drawer's **Offers** tab.

<Callout type="note">
Create the discount code in your Shopify admin first. Offers use codes that already exist.
</Callout>

## Create an offer

<Steps>

1. Go to **Slide Cart Drawer**, open the **Offers** tab and click **Create Offer**.
2. Fill in the **Title** and **Description**.
3. Choose the **Offer type** and enter the **Discount code**.
4. Set **Button text**, **Redirect URL**, **Image URL**, **Terms and conditions** and **Validity** as needed.
5. Save the offer.

</Steps>

Make sure **Show cart offers** is on in **Customize**, or the tab won't show.

## Tips

- Use `{TIMER}` in the **Description** to show a countdown timer.
