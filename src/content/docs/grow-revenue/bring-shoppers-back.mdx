**Goal:** give shoppers who left a reason to return.

## Try

1. **Web Push** with a specific offer that links to the right product. See [Send a notification](/web-push/send-notification/).
2. **Send Discount Code** from the **Live Cart** for an active cart that needs a nudge. See [Live Cart and notifications](/slide-cart/live-cart/).
3. **Cart Offers** with a code shoppers can use right away. See [Cart Offers](/slide-cart/cart-offers/).

## Measure it

Use **Web Push** analytics, and check orders using the discount code in Shopify. See [Read your analytics](/guides/analytics/).
